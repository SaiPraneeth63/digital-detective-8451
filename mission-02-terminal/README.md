## 3. Commands / tools used
- `pwd`: Displays the full path of the current working directory.
- `ls`: Lists directory contents (used with `-la` and `-h` flags for detailed, hidden, and human-readable views).
- `cd`: Changes the current working directory.
- `mkdir`: Creates a new directory.
- `echo` with `>` / `>>`: Creates files or appends text without overwriting existing content.
- `cat`: Displays the contents of a text file.
- `cp` / `mv`: Copies or moves/renames files.
- `|` (Pipe): Passes output from one command as input to another.

## 4. My understanding
The Terminal provides an efficient text-driven interface to interact directly with the operating system. Command flags modify how operations behave to reveal hidden details or format outputs, while pipes enable powerful combinations of tools. Package managers streamline software installation, updates, and dependency management.
